How It Works

The classification model is trained only once. The trained model produces fraud probabilities for the test data.

The threshold determines whether a transaction is classified as Fraud or Not Fraud.

Move the threshold slider above to see how Accuracy, Precision, Recall, F1-Score and the Confusion Matrix change.
